## 🛡️ What Is Custos?

**Custos** is a free, open-source, **local-first guardian for sensitive financial data**. It is designed to help you protect financial details **before they reach AI chats and tools**, so you can use AI assistants without handing over information you meant to keep private.

Built by [LYF Mail](https://lyfmail.com), a [privacy-first digital wellness platform](https://lyfmail.com) serving 50,000+ subscribers across India since 2020, Custos extends our mission of **"Every Choice Shapes Tomorrow"** into everyday tools that people can trust.

---

## 🧭 Why Custos Exists

- 🤖 **AI chat tools are now part of everyday work**, including work that involves money.
- 💳 **Financial details** such as account and card information are easy to paste by accident.
- ☁️ **Once text is sent to an online service,** you can no longer control where it goes.

**Custos puts a local check between your financial data and AI tools** — built on a local-first approach and LYF Mail's privacy-first principles.

---

## ✨ Key Features

- **🛡️ Financial Data Guard** — Helps protect sensitive financial information before it is shared with AI.
- **💻 Local-First** — Designed to do its work on your own device.
- **🤖 Built for AI Chat Workflows** — Made for people who use AI assistants alongside financial documents and details.
- **🔒 Privacy-First by Design** — Built on LYF Mail's principle of minimal data collection.
- **🆓 Free & Open Source** — No subscription fees. Fully auditable code under the MIT License.

## 🚀 Quick Start Guide

### For Users

1. **Visit** [custos.lyfmail.com](https://custos.lyfmail.com).
2. **Start using Custos** straight from your browser.
3. **Add it to your home screen** if your browser offers an install option, for quick access.

### For Developers

1. **Clone the repository**
```bash
git clone https://github.com/lyfmail-official/custos.git
cd custos
```

2. **Serve locally** with any static file server
```bash
# Python 3
python -m http.server 8080

# Or with Node.js
npx serve .
```

3. **Open in your browser**
```
http://localhost:8080
```

## 🤝 Contributing to Custos

Custos welcomes contributions that respect our core principles:

- **Privacy-first** — never introduce tracking, analytics, or unnecessary data collection.
- **Minimal dependencies** — prefer built-in web platform features over heavy frameworks.
- **Performance-focused** — optimize for low-end devices, slow networks, and limited battery.
- **Accessibility-first** — every feature must work for users with disabilities.
- **Local-first** — sensitive data must be processed on the user's device and never sent to a server.

Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) before submitting pull requests. To report a vulnerability, see [`SECURITY.md`](SECURITY.md).

## 💬 Frequently Asked Questions

**Q: Is Custos really free to use?**  
A: Yes. Custos is free to use and open source under the MIT License. It is a project by [LYF Mail](https://lyfmail.com), committed to making useful privacy-first tools accessible to everyone.

**Q: How does Custos handle my data?**  
A: Custos is built on LYF Mail's **privacy-first principles**: collect as little data as possible and keep control with the user. Because Custos is open source, you can inspect exactly how it works in the [source code](https://github.com/lyfmail-official/custos).

**Q: Does Custos guarantee that no sensitive data reaches an AI tool?**  
A: No. No tool can guarantee that. Custos is an **additional safeguard**, not a substitute for your own judgement. Always review any text before you share it with an AI service.

**Q: Is Custos financial or legal advice?**  
A: No. Custos is a privacy tool. It does not provide financial, legal, or compliance advice.

**Q: Can I contribute to Custos?**  
A: Yes. We welcome developers, designers, writers, translators, and accessibility advocates. Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) first.

**Q: How do I report a bug or a security issue?**  
A: Open a [GitHub issue](https://github.com/lyfmail-official/custos/issues) for bugs. For security vulnerabilities, **do not** open a public issue — follow [`SECURITY.md`](SECURITY.md).
